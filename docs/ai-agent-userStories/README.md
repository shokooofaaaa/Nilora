# ایجنت بازبینی User Story

یک ایجنت (با OpenCode) که User Storyهای خام را بر اساس قوانین فصل ۲ کتاب
Head First Software Development بازبینی می‌کند و نسخه استاندارد را در یک گزارش می‌نویسد.

## ایده (Harness)

به‌جای اینکه به مدل بگوییم «هر کاری دوست داری بکن»، چارچوبش را مشخص می‌کنیم

 بخش  فایل 
------
 قوانین و محدودیت‌ها  `rules.md` 
 ورودی خام  `bad-story.md` 
 خروجی استاندارد  `review-report.md` 

## فایل‌ها

- `rules.md` قوانین بازبینی
  - حذف کلمات و ردفلگ‌های فنی (مثل «جدول SQL») از داستان
  - قانون AND داستان بزرگ که چند کار را با «و» به هم وصل می‌کند، به چند داستان کوچک شکسته شود
  - تمرکز بر ارزش واقعی مشتری
- `bad-story.md` چند داستان عمداً شلخته و غیرمهندسی (ورودی آزمایشی)
- `review-report.md` خروجی ایجنت؛ داستان‌های اصلاح‌شده و قابل‌تخمین

## نحوه اجرا

```bash
npm install -g opencode-ai
opencode --version
opencode console login
```

سپس این دستور به ایجنت داده می‌شود

 فایل rules.md را بخوان و کل داستان‌های bad-story.md را ریویو کن و نتیجه استاندارد را در review-report.md ذخیره کن.

## نتیجه

ایجنت بدون دخالت دستی داستان‌های دارای کلمات فنی را اصلاح کرد و داستان‌های حجیم را
به چند داستان استاندارد و قابل‌تخمین تقسیم کرد.

## نکته

این ایجنت داستان‌ها را بازبینی می‌کند و از صفر نمی‌نویسد.
داستان‌های نهایی نیلورا در `docsrequirements` هستند.
